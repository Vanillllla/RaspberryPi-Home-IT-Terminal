# Создание проекта виджета

## Первый проект в браузере

Откройте «Создать виджет». Конструктор начинает с пустого проекта. На вкладке «Проект» задайте постоянный ID папки, названия и описания на двух языках. ID начинается со строчной латинской буквы и допускает цифры и дефис. После первого сохранения ID закреплён. Повторно открыть проект можно в списке «Библиотека».

1. На вкладке «Дизайн» выберите «Карточка» (Widget). Нажмите «Текст» в палитре или перетащите его на холст. Через инспектор задайте ID `message` и начальный текст. Добавьте кнопку с ID `refreshButton`. Для совпадающих по положению элементов пользуйтесь деревом.
2. Выберите кнопку. Рядом с onClick введите `refresh` и нажмите «Создать функцию». В общем модуле замените pass на строку ниже. Добавляйте вспомогательные функции в тот же редактор. К существующему обработчику можно перейти кнопкой «К функции».
3. Нажмите «Проверить Python», затем «Предпросмотр». Нажатие кнопки в тестовом экземпляре должно обновить текст. Черновик в это время существует только в редакторе. Тестовые результаты доступны только в текущем предпросмотре.
4. Нажмите «Сохранить проект», закройте конструктор и выберите проект через «+ Виджет». Добавьте второй экземпляр и сравните их значения.

```python
def refresh(ctx):
    ctx.set("message", "text", "OK", persist=True)
```

## Холст и представления

Переключатели «Карточка», «Подробнее» и «Настройки» открывают представления Widget, Details и Settings.

Одна внешняя клетка равна 96 × 96 логическим пикселям. Размер Widget задаётся в клетках в инспекторе корневого узла. У Details и Settings собственные размеры в логических пикселях. Изменение высоты проекта добавляет или убирает пространство по вертикали. Геометрия узлов сохраняется. Поле масштаба меняет обе оси одним коэффициентом. Для большого холста используйте прокрутку.

Выберите узел нажатием или в дереве. Потяните его или нижний правый маркер для изменения размера. Свободное размещение использует шаг 8 px и направляющие по граням и центрам соседей. Введите точные X, Y, ширину и высоту через инспектор. Кнопки «Назад» и «Вперёд» меняют порядок наложения или положение в потоке. Дочерние координаты отсчитываются от родителя. Для клавиатуры доступны палитра, дерево, поля геометрии и выбор родителя. При сенсорном вводе нажмите элемент палитры, затем перемещайте его на холсте.

Добавьте «Контейнер». При выборе контейнера новые элементы попадают внутрь него. Родителя можно изменить в инспекторе. Свободная компоновка использует координаты. Строка и колонка используют порядок дочерних узлов, отступ и поперечное выравнивание. В них флаг «Занимать свободное место» распределяет остаток длины. Для адаптивного корня выберите строку или колонку в инспекторе представления.

Вкладки Details и Settings позволяют создать дополнительные представления. У всех узлов проекта уникальные ID, включая вложенные узлы трёх представлений. ID начинается с латинской буквы, далее допустимы буквы, цифры и подчёркивания. При переименовании ID исправьте обращения к нему в Python. Повторное использование прежнего ID связывает узел с сохранёнными свойствами этого ID в экземплярах. Выполнение события в любом представлении обновляет состояние того же экземпляра. Стрелка в заголовке открывает Details, меню ⋯ → «Настройки» открывает Settings вместе с индивидуальными параметрами.

## Папка на диске

Для ручного создания скопируйте либо создайте папку в widgets/. Минимальный рабочий пример состоит из manifest.json и logic/main.py. Первый файл описывает проект, второй содержит обычный Python. Добавьте assets/ для ресурсов и README.md для заметок. Имя папки должно совпадать с id. Остановите backend перед ручной правкой и запустите его снова для обнаружения изменений.

```json
{
  "apiVersion": 1, "id": "hello-panel", "version": "1.0",
  "name": {"en": "Hello", "ru": "Привет"},
  "description": {"en": "Event example", "ru": "Пример события"},
  "width": 3, "height": 2, "logic": "logic/main.py",
  "views": {"widget": {"nodes": [
    {"id": "message", "type": "text", "frame": {"x": 8, "y": 8, "w": 220, "h": 48}},
    {"id": "refreshButton", "type": "button", "frame": {"x": 8, "y": 72, "w": 150, "h": 48},
     "props": {"text": "OK"}, "events": {"onClick": "refresh"}}
  ]}}
}
```

views.details и views.settings могут отсутствовать или иметь значение null. Узел содержит type, id, frame, props, events и при необходимости children и layout. Размеры w и h положительны. Координаты неотрицательны. Размер Widget — 1–12 × 1–24 клетки. Размеры остальных представлений задают views.<имя>.width и height. Внутренняя геометрия и z-порядок общие для всех экземпляров.

Метаданные author, version и icon описывают автора, версию и относительный путь к растровой иконке в assets. Поле strings сопоставляет исходные строки с переводами вида {"ru":"…","en":"…"}. Оно применяется к локализуемым свойствам модулей. Поле dependencies содержит списки elements, python и host. При сохранении конструктор включает используемые типы элементов. Python-пакеты устанавливает владелец в окружение backend. Имена системных операций появляются в справке по установленным интеграциям.

Редактор записывает Python в logic/<хеш>.py и последним атомарно заменяет manifest.json с указателем logic. При ручном редактировании следуйте текущему значению logic. Это позволяет сохранить все три интерфейса и модуль как одну ревизию. Собственные файлы, README и ресурсы остаются в папке. Скопировать или передать проект можно целой папкой. При двух параллельных правках сервер отклоняет запись устаревшей ревизии с HTTP 409. Черновик остаётся открыт.

## Экземпляры, конфликты и синхронизация

SQLite хранит рабочие столы, позиции, разрешённые переопределения, индивидуальные параметры, сохраняемые свойства и ряды данных. Копия ширины и высоты в строке экземпляра нужна для проверки пересечений и заглушки при отсутствии проекта. Значения определяет проект. При сохранении нового размера движок оставляет соседние проекты на месте, пытается сохранить прежние позиции изменяемых экземпляров и ищет свободные прямоугольники для остальных. Если разместить очередной экземпляр не удаётся, ответ указывает стол. Освободите место или перенесите виджет и повторите сохранение.

Вкладка «Проект» задаёт исходные название карточки, видимость заголовка и цвета. Пользователь экземпляра может переопределить эти четыре значения и сбросить их до проектных. Функциональный параметр объявляется в settings с типом, подписями и значением по умолчанию. Работа с ним доступна через ctx.setting и ctx.set_setting. Для секрета используйте тип secret и системное поле пароля в настройках. Временные значения свойств находятся в памяти backend. Ревизия и уведомление общего WebSocket сообщают клиентам, что пора получить актуальный REST-снимок.

При удалении модуля элемента на его месте появится заглушка с ID типа. Исходный узел, геометрия и свойства хранятся в проекте. При отсутствии проекта сохраняется размещение со ссылкой на его ID. Восстановите папку и перезапустите соответствующие процессы.

## Четыре рабочих примера

- signal-lab читает в обработчике кнопки значения переключателя и слайдера. Значение результата сохраняется между запусками, цвет индикатора временный.
- station-panel связывает настройки, подробности и карточку. Измените имя в Settings и нажмите Enter. Откройте Details и запустите проверку. Сравните с другим экземпляром.
- sample-monitor пишет тестовую серию каждые две секунды, а Details показывает график с метками времени. Закройте браузеры, подождите и откройте панель. Затем переопределите режим экземпляра на «При отображении» и повторите.
- gauge-lab читает и меняет свойства отдельного модуля circular-gauge. Для проверки заглушки остановите сервер, временно переместите папку элемента за пределы elements/, перезапустите backend и пересоберите frontend. Верните папку и повторите запуск.

Полные сигнатуры, ошибки и примеры приведены в [справочнике Python](PYTHON_API.md). Создание нового типа интерфейса описано в [руководстве по элементам](ELEMENTS.md).
