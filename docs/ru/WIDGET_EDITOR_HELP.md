# Python API · версия 1

## Обработчик и контекст

Назначьте событию синхронную функцию верхнего уровня с одним аргументом ctx. Все функции проекта находятся в одном модуле. При каждом вызове сервер загружает его в отдельный процесс Python из окружения backend. Можно импортировать стандартную библиотеку и установленные в окружение пакеты. Переменные модуля живут один вызов. Обычный return возвращает результат вызывающей функции. Для обновления интерфейса используйте ctx.set.

```python
def label_for(level):
    return f"{level} °C"

def refresh(ctx):
    level = ctx.get("temperature", "value")
    ctx.set("caption", "text", label_for(level))
    ctx.set("lamp", "color", "red" if level > 50 else "green")
```

## Свойства

ctx.get(element, prop) возвращает копию значения. Адресом служит один и тот же ID во всех трёх представлениях экземпляра. Порядок приоритета от низкого к высокому — значение из manifest элемента, свойство узла проекта, сохранённое свойство экземпляра, временное свойство. Изменения входа из текущего события уже видны обработчику. На входах и в Python используются исходные строки проекта. Перевод подписей выполняется при отображении.

ctx.set(element, prop, value, persist=False) проверяет значение по контракту установленного элемента, меняет его в контексте и возвращает None. При persist=True значение переживает перезапуск. Временная запись поверх сохраняемой видна всем клиентам до перезапуска или следующей сохраняемой записи того же свойства. За одно событие можно сделать обе записи. Свойства JSON принимают списки, объекты и скаляры JSON. Модифицированную копию из get нужно передать в set.

```python
def advance(ctx):
    value = ctx.get("myGauge", "value") + 1
    ctx.set("myGauge", "value", min(value, 100), persist=True)
    ctx.set("myGauge", "color", "#157552")
```

Неизвестные ID, свойства и параметры вызывают KeyError. Недопустимый тип, диапазон, цвет, вариант или размер JSON вызывает ValueError либо TypeError. Числа должны быть конечными. Для boolean передавайте True или False. Для строки — str. Числовой слайдер отдаёт число, поле ввода отдаёт строку. Ошибка прерывает событие и отменяет всю группу изменений модели. Редактор и карточка показывают тип ошибки и строку кода, когда она известна. Внешние HTTP-запросы и операции хоста имеют собственные побочные эффекты.

## Экземпляр и настройки

ctx.instance_id содержит числовой ID размещения. В предпросмотре это None. ctx.setting(name) возвращает значение объявленного параметра или его значение по умолчанию. ctx.set_setting(name, value) записывает проверенное значение в индивидуальные настройки и возвращает None. Объявляйте параметры на вкладке «Проект». Для токена задайте тип secret с пустой строкой по умолчанию. Введите токен в поле пароля в настройках экземпляра. Сервер сообщает браузерам только факт наличия секрета. Не помещайте секрет в текст элемента, исходник, историю, URL или диагностическое сообщение.

```python
def apply_name(ctx):
    name = ctx.get("nameInput", "value").strip()
    ctx.set_setting("stationName", name)
    ctx.set("cardTitle", "text", name, persist=True)
```

## События

ctx.event — словарь с ключами name, element и changes. Для периодической задачи имя равно tick, а element равен None. Компонент может записать через событие только свойства из списка writes его контракта. Входы события обновляются временно. Для сохранения входа вызовите set с persist=True.

ctx.call(name) синхронно вызывает функцию из общего модуля с тем же ctx и возвращает её результат. ctx.emit(name) вызывает обработчик именованного события из таблицы events проекта и возвращает результат. Внутри него ctx.event описывает внутреннее событие. После возврата восстанавливается исходное. Вложенность диспетчеризации ограничена 24 вызовами. Можно также напрямую вызывать функции Python с любыми аргументами.

```python
def apply(ctx):
    ctx.set("power", "value", ctx.get("power", "value"), persist=True)
    ctx.emit("updated")  # events = {"updated": "refresh"}

def refresh(ctx):
    ctx.set("lamp", "color", "green" if ctx.get("power", "value") else "red")
```

Внешний клиент доверенной сети может отправить именованное событие проекта запросом POST /api/widgets/ID/events с JSON {"name":"updated"}. Укажите revision из снимка проекта, чтобы отклонить событие для устаревшего интерфейса.

Если в events проекта объявлено событие settingsChanged, сохранение функциональных параметров через форму экземпляра запускает его с новыми настройками. Запись полей и результата обработчика выполняется одной транзакцией. Из обычного обработчика после ctx.set_setting можно вызвать ctx.emit("settingsChanged") для того же пересчёта.

## Периодические задачи и графики

В поле «Периодический обработчик» укажите имя функции. Режим «В фоне» запускает её на сервере и при закрытых браузерах. «При отображении» учитывает видимость экземпляра хотя бы у одного клиента. «По событиям» выключает таймер. Интервал 1–86400 секунд. Режим и интервал можно менять для каждого экземпляра. После запуска или возобновления задача становится готовой к немедленному выполнению. Долгие вызовы одного экземпляра выполняются последовательно. Сервер обслуживает до трёх периодических задач одновременно. При высокой нагрузке отсчёты могут запаздывать.

ctx.sample(series, value) добавляет конечное число с серверной меткой времени Unix и возвращает None. Имя ряда начинается с латинской буквы, длина до 64, допустимы буквы, цифры и _. База хранит последние 3600 точек каждого ряда каждого экземпляра. ctx.history(series, limit=120) возвращает от нуля до limit пар [время, значение] от старых к новым, включая точки текущего вызова. Диапазон limit — 1–3600. Для графика передайте пары в свойство points модуля line-chart.

```python
from math import sin
from time import time

def measure(ctx):
    value = round(50 + 30 * sin(time() / 12), 1)
    ctx.sample("signal", value)
    ctx.set("current", "text", str(value))
    ctx.set("plot", "points", ctx.history("signal", 240), persist=True)
```

## HTTP, ресурсы и интеграции

Обычный Python выполняет HTTP-запросы со стороны хоста. Пример предполагает параметр endpoint и ответ JSON с полем temperature. Укажите таймаут меньше общего лимита вызова.

```python
import json
from urllib.request import urlopen

def read_sensor(ctx):
    with urlopen(ctx.setting("endpoint"), timeout=3) as response:
        reading = json.load(response)["temperature"]
    ctx.set("temperature", "text", f"{reading} °C")
```

ctx.asset(name) возвращает pathlib.Path существующего файла в assets проекта. Отсутствующий или выходящий за каталог ресурс вызывает FileNotFoundError. Растровые иконки также доступны компоненту через его функцию asset.

ctx.invoke(name, *args) запускает установленную операцию хоста. Имена и число аргументов перечислены в справке конструктора. Установите интеграцию в integrations/ИМЯ/operations.json и перезапустите backend. Каждый ключ файла описывает операцию с массивом argv, начинающимся с абсолютного пути к программе, и числом дополнительных аргументов inputs. Пример тестового описания — {"echo":{"argv":["/usr/bin/echo"],"inputs":1}}. Для папки demo вызов ctx.invoke("demo/echo", "hello") возвращает строку вывода. Аргументы передаются программе отдельно, объекты сериализуются в JSON. Выполнение занимает до пяти секунд. Ошибки включают KeyError, ValueError, OSError и исключения subprocess. Последовательности операций и выбор аргументов оформляйте как обычные функции, связывайте их с кнопками, внутренними событиями или таймером.

## Выполнение и диагностика

Один вызов занимает до восьми секунд реального времени, до шести секунд CPU с жёстким пределом семь и до 384 МиБ адресного пространства. Суммарный JSON результата ограничен 2 МиБ, одно свойство JSON — 256 КиБ сериализованного текста. Это пределы ресурсов для доверенного кода. Python работает с правами пользователя backend. Устанавливайте проекты и элементы только из доверенных источников. Обновление проекта или конфигурации во время долгого вызова отклоняет устаревший результат. Удаление экземпляра удаляет его ряды и значения.

«Проверить Python» проверяет синтаксис и наличие назначенных функций. «Предпросмотр» позволяет нажимать элементы, переключать представления и запускать обработчик таймера вручную. Тестовый экземпляр имеет отдельные значения и историю. Внешние операции из тестируемого Python действительно выполняются. Для проверки мониторинга без браузеров разместите sample-monitor на рабочем столе.
