# Необязательный запуск через Electron (экспериментальный)

Обычный запуск в браузере не изменён. Electron использует уже запущенную локальную панель Vite и FastAPI, а не заменяет их. Требуется 64-битная ОС (arm64 для Raspberry Pi 5), графический сеанс, Node.js 22.12+ и системные библиотеки Chromium/GTK. Не запускайте от root и не отключайте sandbox.

## Первый запуск

Из корня проекта выполните обычную установку из README, затем:

```bash
npm --prefix electron install
npm --prefix electron test
```

В двух терминалах запустите существующие сервисы:

```bash
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

```bash
npm --prefix frontend run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

В третьем терминале (в графическом сеансе Raspberry Pi):

```bash
npm --prefix electron start
```

При повторном запуске нужны только три команды запуска. В обычном браузере по-прежнему можно открыть http://127.0.0.1:5173. Закрытие Electron не останавливает backend и Vite.

## Виджет и элемент

Нажмите «+ Виджет» → ChatGPT (6×4 клетки). При необходимости освободите место или измените размеры проекта в конструкторе. Элемент «Браузер» (browser-view) поддерживает URL HTTPS и масштаб. Настоящая страница показывается только в полностью видимых карточках на рабочем столе Electron. В конструкторе, Details, Settings и обычном браузере — ссылка. Ссылка «Открыть отдельно» всегда доступна и открывает системный браузер. Войдите в аккаунт внутри ChatGPT самостоятельно.

Сессия внешних сайтов сохраняется в отдельном профиле Electron, не совпадающем с Chromium. Содержимое сайта не модифицируется, API OpenAI и Codex не используются. Внешние окна, загрузки и дополнительные разрешения запрещены. Для ChatGPT разрешены известные домены входа, но OAuth, CAPTCHA, вход и работа ChatGPT в Electron требуют ручной проверки; альтернативный вход в системном браузере не переносит сессию в Electron.

До трёх браузерных областей сохраняются в памяти; скрытые области могут быть вытеснены. При прокрутке, переносе, переключении стола и открытии диалога область временно скрывается. Нативные области не поддерживают произвольное наложение поверх других элементов; используйте отдельный неперекрывающийся прямоугольник. Это локальная экспериментальная оболочка для доверенной панели. Ограничение явных локальных адресов не является сетевым firewall.

## Проверка

Запустите npm --prefix electron test и npm --prefix frontend run build. Проверьте вход, отправку сообщения, перезапуск Electron, смену стола, диалоги, перенос и изменение размеров. Проверьте fallback в обычном Chromium. При ошибке загрузки воспользуйтесь внешней ссылкой; перезапуск оболочки позволяет повторить загрузку. Electron 45.4.1 выбран отдельно от зависимостей frontend; регулярно обновляйте его до актуальной исправленной версии.
