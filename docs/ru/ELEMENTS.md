# Разработка модуля элемента

Создайте elements/pulse-button/manifest.json и Component.tsx. Имя папки равно id, компонент экспортируется по умолчанию. В папке можно хранить свои CSS, вспомогательные компоненты и README. Рабочий пример независимого модуля находится в elements/circular-gauge/.

```json
{
  "apiVersion": 1, "id": "pulse-button", "version": "1.0.0",
  "name": {"ru": "Импульс", "en": "Pulse"},
  "description": {"ru": "Передаёт счётчик на сервер", "en": "Send a count to the server"},
  "defaultFrame": {"x": 0, "y": 0, "w": 128, "h": 48},
  "properties": {
    "count": {"type": "number", "default": 0, "min": 0,
              "label": {"ru": "Счётчик", "en": "Count"}},
    "label": {"type": "string", "default": "Pulse", "localized": true,
              "label": {"ru": "Подпись", "en": "Caption"}}
  },
  "strings": {"Pulse": {"ru": "Импульс", "en": "Pulse"}},
  "events": {"onPulse": {"description": {"ru": "Нажатие", "en": "Pressed"}, "writes": ["count"]}}
}
```

```tsx
import type { ElementProps } from '@terminal/element'

export default function PulseButton({ properties, emit }: ElementProps) {
  return <button onClick={() => emit('onPulse', { count: Number(properties.count) + 1 })}>
    {String(properties.label)} · {Number(properties.count)}
  </button>
}
```

Backend сканирует манифесты при старте. Vite обнаруживает Component.tsx по шаблону elements/*/Component.tsx. Перезапустите backend и dev-сервер или пересоберите frontend. «Импульс» появится в поиске палитры, инспекторе, списке событий и справочнике элементов. Добавьте его в виджет, выберите onPulse и создайте обработчик. Например, `ctx.set("pulseButton1", "count", ctx.get("pulseButton1", "count"), persist=True)` сохранит актуальный счётчик. Для интеграционного теста откройте ещё один браузер и сравните значения двух клиентов.

## Контракт

- apiVersion — версия контракта платформы, сейчас 1. version — версия модуля. id — постоянный идентификатор типа. Имя и описание имеют переводы ru и en.
- properties — словарь именованных свойств. Для каждого укажите type, default и label на двух языках. Необязательное description служит подсказкой инспектора и попадает в справку. Доступны string, number, boolean, color, choice и json. Цвет — имя CSS или HEX, choice перечисляет варианты в options, number допускает min и max. Для данных графика используйте свойство json. Секреты объявляются в настройках проекта.
- events — словарь событий с двуязычным описанием. Массив writes разрешает компоненту прислать изменения именно этих свойств вместе с событием. Например, onChange с writes ["value"] обновляет ввод и затем вызывает привязанную функцию одним событием. Событие кнопки может иметь пустой writes. Python может менять все объявленные свойства.
- Значения, поступающие в React, уже учитывают проект и состояние экземпляра. localized применяет словарь strings к отображаемым строкам. Python читает исходное значение. Через ElementProps доступны id узла, properties, language, emit(name, changes?) и asset(filename). asset строит URL растрового файла из папки проекта widgets/<id>/assets/. Используйте language для подписей и формата дат.
- container: true позволяет принимать children. Отобразите children в области с определёнными шириной и высотой. Внутренней компоновкой управляет движок. Для обычного элемента достаточно одного доступного контрола, занимающего выданную область.
- Храните авторитетные значения на сервере. Временный текст до подтверждения или положение бегунка во время жеста могут жить в React. Таймеры мониторинга и историю размещайте в проекте виджета.
- Используйте семантические кнопки, подписи полей и навигацию с клавиатуры. Для CSS ограничивайте селекторы собственным компонентом. Ошибка его рендера изолируется границей React. Отсутствующий тип получает заглушку в исходном прямоугольнике.

## Выпуск новой версии

Добавляйте свойства со значениями по умолчанию. Сохраняйте смысл старых имён, чтобы существующие проекты могли использовать обновлённый модуль. Для несовместимой схемы выпустите модуль с новым id и измените проекты осознанно. После обновления проверьте свои манифесты, сборку TypeScript, виджет с двумя экземплярами и оба языка. Реестр и справочник получают данные из установленных пакетов.
