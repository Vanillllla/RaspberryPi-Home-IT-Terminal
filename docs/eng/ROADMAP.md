# Roadmap

## Delivered

v0.4.0 established desktops, placement, touch navigation and cross-browser synchronization. The previous widgets and designer sources are preserved under archive/.

v0.5.0 adds file-based projects, independent element modules, one three-view renderer and a Python API. The designer edits, previews and publishes a revision. The server owns instance settings, temporary and durable properties, background scheduling, client visibility and sample history. Four demonstration projects ship in the library.

## Next stage

Measure memory and CPU on a physical Raspberry Pi 5, verify a 7–10 inch touchscreen and test recovery after reboot. Use the measurements to scope systemd startup and Chromium kiosk operation. Select real integrations in separate iterations. Network package installation and permissions are future work.
