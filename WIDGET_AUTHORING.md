# Как подготовить виджет для импорта в RaspberryPi-Home-IT-Terminal

**Результат работы автора — папка с одним файлом `template.json`.** Файл описывает общий шаблон для визуального конструктора. После импорта он появляется в каталоге. Пользователь отдельно добавляет экземпляры шаблона на рабочие столы. Позиция, размер, оформление и текущие значения принадлежат каждому экземпляру.

## Папка и ZIP

```text
hello-card/
└── template.json
```

Имя папки выбирает автор. Имя файла фиксировано, в нижнем регистре. Файл обязательный, дополнительных файлов в формате нет. Сохраните обычный текстовый JSON в UTF-8, без комментариев и завершающих запятых. Даже код действия Python хранится строкой внутри JSON.

Для ZIP выполните команду из каталога, **содержащего** папку виджета. Например, для первого примера команда создаст архив с записью `hello-card/template.json`:

```bash
python3 -m zipfile -c hello-card.zip hello-card/
```

Проверьте, что в архиве один обычный файл на глубине ровно одной папки. Запись самой папки допустима. Уберите служебные файлы, включая `.DS_Store`. Используйте относительные пути с разделителем `/`. Импортёр отклоняет абсолютные пути, компоненты `.` и `..`, префиксы дисков, обратные косые черты и символические ссылки. Поддерживаются ZIP без пароля, с методом **Deflate** или **Stored**. Лимит для загружаемого архива и отдельно для распакованного JSON — по 8 МиБ.

## Поля шаблона

Корень JSON — объект. Типы проверяются строго. Например, интервал в одну секунду записывается числом `1`, включённый переключатель — значением `true`.

| Поле | Тип и обязательность | Содержание |
|---|---|---|
| `id` | строка, обязательно | Уникальный ID шаблона по выражению `^template:[0-9a-f]{32}$`. После префикса идут 32 строчные шестнадцатеричные цифры без дефисов. |
| `name` | строка, обязательно | Название в каталоге и на карточке, 1–100 символов, хотя бы один непробельный символ. |
| `rows` | массив массивов объектов, обязательно | От 1 до 64 строк. Всего в шаблоне от 1 до 128 элементов. |
| `actions` | массив объектов, обязательно | До 64 действий. Для статической карточки укажите `[]`. |
| `description` | строка, необязательно | Описание для каталога, до 2000 символов. По умолчанию пустое. Импорт убирает пробелы по краям. |
| `revision` | целое число, необязательно | Служебная ревизия. При создании пакета поле можно опустить. Импорт присваивает первую ревизию `1`. |

Для **нового** шаблона сгенерируйте собственный ID, например командой `python3 -c 'import uuid; print("template:" + uuid.uuid4().hex)'`. Повторный импорт занятого ID отклоняется, даже при другом названии папки. Установленный шаблон редактируется в конструкторе.

### Строки, колонки и элементы

Каждый внутренний массив в `rows` задаёт одну строку. Каждый объект в нём занимает очередную колонку. Так, при структуре `[[A, B], [C]]` элементы A и B стоят рядом, C расположен ниже. При нехватке ширины элементы строки переносятся. Порядок задают сами массивы.

У каждого элемента обязательны три строки: `id`, `kind` и `label`. ID элемента соответствует `^[A-Za-z][A-Za-z0-9_-]{0,63}$` и уникален среди элементов **всех** строк шаблона. Поле `label` содержит подпись длиной до 2000 символов. Связи используют ID, поэтому подпись можно менять.

| Значение `kind` | Поведение и дополнительные поля |
|---|---|
| `text` | Показывает `label` до первого результата. Без привязанного действия текст остаётся статическим. |
| `button` | Показывает `label`. При нажатии отправляет необязательную строку `command`. |
| `switch` | Переключатель с подписью. Начальное значение `checked` имеет тип boolean, по умолчанию `false`. При изменении может отправить `command`. |
| `slider` | Слайдер с подписью. Числовые поля `minimum`, `maximum`, `step`, `initial` по умолчанию равны 0, 100, 1 и 0 соответственно. При изменении может отправить `command`. |
| `indicator` | Цветной кружок. Подпись используется в подсказке и доступном названии. Начальный `color` — одна из строк `green`, `yellow`, `red`, по умолчанию `green`. |

Числа слайдера должны быть конечными, `minimum < maximum`, `step > 0`. Начальное значение должно лежать в диапазоне включительно и попадать на шаг от минимума. Например, при диапазоне от −1 до 1 и шаге 0.25 значение 0.5 допустимо. У всех отправителей `command` по умолчанию пустая строка, максимум 100 символов.

## Действия и назначение результата

Каждая запись в `actions` содержит обязательные поля:

| Поле | Тип и значения |
|---|---|
| `id` | Строка по тем же правилам, что ID элемента. Уникальна среди действий шаблона. |
| `name` | Название действия для редактора, строка длиной 1–100 символов. |
| `kind` | Строка `time`, `reach`, `http` или `python`. |
| `trigger` | Строка `command` или `timer`. |
| `targets` | Массив до 128 назначений результата. Для запуска из карточки укажите хотя бы одного получателя. |

**По команде.** Укажите в действии непустую строку `command` до 100 символов, например `refresh`. Та же строка должна стоять у кнопки, переключателя или слайдера этого шаблона. Совпадение точное, с учётом регистра. Одна команда может запустить несколько действий. Она действует только внутри экземпляра, где пользователь её отправил.

**По таймеру.** Укажите `"trigger": "timer"` и при необходимости `interval` — целое число секунд от 1 до 86400, по умолчанию 1. На активном рабочем столе действие запускается сразу, затем периодически. При уходе со стола или скрытии вкладки таймер останавливается. Пока предыдущий запуск этого действия в экземпляре выполняется, следующий такт пропускается. Например, для текстового элемента с ID `clockText` запись в массиве `actions` может выглядеть так:

```json
{"id":"tick","name":"Обновить часы","kind":"time","trigger":"timer","interval":1,"targets":[{"element":"clockText"}]}
```

**Получатели.** В каждом объекте `targets` обязательна строка `element` с ID существующего `text` или `indicator`. Необязательная строка `field` до 256 символов выбирает часть результата. При отсутствии `field` или значении `""` берётся весь результат. Точка разделяет ключи объекта, десятичный индекс выбирает элемент массива, например `sensors.0.value`. Результат для текста отображается строкой, остальные JSON-значения сериализуются в текст. Для индикатора результат должен быть точно `"green"`, `"yellow"` или `"red"`.

Одно действие может заполнить несколько получателей. Каждый получатель может быть указан только один раз во всём шаблоне. Чтобы задать режим «Без обновления», оставьте элемент вне всех списков `targets`.

### Что возвращает каждый вид действия

| `kind` | Входные данные | Результат |
|---|---|---|
| `time` | Дополнительные поля не нужны. | Строка с локальным временем сервера в формате `HH:MM:SS`. Назначьте её тексту целиком. |
| `reach` | `host` — имя хоста или IP без схемы URL, до 253 символов. При отсутствии `port` или значении `null` выполняется ICMP-проверка (в Debian нужен `iputils-ping`). Целый `port` от 1 до 65535 выбирает TCP-проверку. | Объект с полями `available` (boolean), `text` («Доступен» или «Недоступен») и `color` (`green` или `red`). |
| `http` | `url` — HTTP(S)-адрес с именем хоста. Сервер выполняет GET и читает JSON, до 1 МиБ. Необязательный строковый `path`, например `cpu.temperature`, выбирает часть ответа. | Выбранное значение, либо весь JSON при пустом `path`. Поле получателя `field` применяется **после** `path`. |
| `python` | `code` — строка до 32768 символов с определением функции `run(context)`. Внутри JSON перенос строки записывается как `\n`. | Значение, возвращённое через `return`, должно сериализоваться в JSON. Удобно вернуть словарь и назначить его поля разным получателям. |

Для Python в `context["values"]` доступны значения элементов своего экземпляра по ID, включая boolean переключателя и число слайдера. Также доступны `context["instance_id"]`, `context["template_id"]` и `context["action_id"]`. Для вычислений уже загружены `math`, `datetime`, `statistics`, `json`, `re`. Функция выполняется в отдельном ограниченном процессе Debian с таймаутом 4 секунды. Используйте готовые действия для сетевых запросов. Вывод `print()` служит диагностикой в карточке.

При импорте сервер проверяет структуру, ссылки и синтаксис Python. Действия запускаются при работе экземпляра. Поэтому для проверки результата нужен размещённый виджет: ошибки выполнения и отсутствующие поля результата отображаются в карточке.

## Пример 1. Карточка с постоянным текстом

Создайте файл **`hello-card/template.json`** со следующим полным содержимым:

```json
{
  "id": "template:fba592d8d6854c808a50c9abc211eb14",
  "name": "Приветствие",
  "rows": [
    [{"id": "greeting", "kind": "text", "label": "Добро пожаловать домой!"}]
  ],
  "actions": []
}
```

## Пример 2. Проверка связи кнопки с действием

Создайте файл **`command-check/template.json`**. Пример проверяет локальную цепочку обновления карточки и работает без внешнего сервиса.

```json
{
  "id": "template:b90cd6aa039f49459af72cc39466ece2",
  "name": "Проверка действия",
  "description": "По нажатию кнопки обновляет сообщение и цвет индикатора.",
  "rows": [
    [{"id": "checkButton", "kind": "button", "label": "Проверить", "command": "refresh"}],
    [
      {"id": "statusText", "kind": "text", "label": "Ожидает проверки"},
      {"id": "statusLight", "kind": "indicator", "label": "Результат проверки", "color": "yellow"}
    ]
  ],
  "actions": [
    {
      "id": "check",
      "name": "Подтвердить выполнение",
      "kind": "python",
      "trigger": "command",
      "command": "refresh",
      "code": "def run(context):\n    return {'message': 'Проверка пройдена', 'color': 'green'}",
      "targets": [
        {"element": "statusText", "field": "message"},
        {"element": "statusLight", "field": "color"}
      ]
    }
  ]
}
```

На новом экземпляре видны «Ожидает проверки» и жёлтый кружок. Нажмите **Проверить**. Команда `refresh` вызовет действие `check` один раз. Поле `message` заменит текст на «Проверка пройдена», а поле `color` сделает кружок зелёным.

## Установка и добавление на стол

**Через интерфейс.** На рабочем столе откройте **Создать виджет → Загрузить шаблон**. Нажмите **Выбрать папку** и укажите, например, саму папку `hello-card`, либо **Выбрать ZIP** и укажите архив с этой папкой внутри. После сообщения об успешном импорте кнопка **Открыть в конструкторе** позволяет проверить и отредактировать шаблон.

**Вручную.** Точный путь от корня репозитория — `template-packages/<имя-папки>/template.json`. Для первого примера в рабочей копии проекта это `/home/user/Projects/RaspberryDashboard/template-packages/hello-card/template.json`. Скопируйте туда папку пакета. Перезапустите backend обычной командой из корня репозитория (при локальном запуске сначала остановите прежний процесс через Ctrl+C):

```bash
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

При запуске backend проверит папки и сохранит новые шаблоны в SQLite. Причина отказа выводится в журнал backend. Если ID уже установлен, сохранённая версия и правки из конструктора сохранятся.

**Размещение одинаково для обоих способов.** На нужном рабочем столе нажмите **+ Виджет** и выберите название шаблона в каталоге. Повторите для второго экземпляра. Открыть общий шаблон позже можно через **Создать виджет → Шаблон**.
