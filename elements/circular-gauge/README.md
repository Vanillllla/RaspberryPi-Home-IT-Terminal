# Circular gauge

**English.** Add Circular gauge from the palette. The `gauge-lab` project reads `value`, updates `color`, and binds `onClick`. Set `minimum`, `maximum`, `enabled` and the accessible `label` in the inspector or in Python. The arc clamps to the declared range. Click, Enter or Space activates the gauge. See [element authoring](../../docs/eng/ELEMENTS.md).

**Русский.** Добавьте «Круговую шкалу» из палитры. Проект `gauge-lab` читает `value`, меняет `color` и назначает функцию на `onClick`. Настройте границы `minimum` и `maximum`, доступность `enabled` и подпись `label` в инспекторе или из Python. Длина дуги ограничена выбранным диапазоном. Нажатие, Enter и пробел активируют шкалу. См. [руководство по элементам](../../docs/ru/ELEMENTS.md).
